# Taller de redes sociales · Estelí 2027

Presentación interactiva del taller de redes sociales y creación de contenidos para negocios turísticos.

- [Presentación](https://silviotif89.github.io/esteli-redes-sociales-2027/)
- [Estudio de publicaciones](https://silviotif89.github.io/esteli-redes-sociales-2027/#22)
- [Formulario de preguntas](https://silviotif89.github.io/esteli-redes-sociales-2027/preguntas.html)
- [Créditos y licencias de las fotografías](assets/esteli/CREDITOS.md)

`index.html` contiene la secuencia y las actividades del taller. Las composiciones visuales, los diagramas y los simuladores están en `assets/`. GitHub Pages sirve el contenido desde la raíz de `main`.

Para revisar una copia local, iniciá un servidor estático en la raíz del repositorio, por ejemplo con `python -m http.server 8734`, y abrí `http://localhost:8734/`. El QR abre el formulario público del taller. El panel del expositor requiere la cuenta autorizada de Firebase.
